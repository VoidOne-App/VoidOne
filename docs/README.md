# VoidOne Documentation

The documentation tree is organized by engineering concern:

- `build.md` — local build and CMake preset workflow.
- `troubleshooting.md` — build, Qt, test, packaging, and runtime diagnostics.
- `architecture/` — architecture and repository boundaries.
- `engineering/` — engineering infrastructure such as AI-assisted repair.
- `release/` — release engineering and distribution procedures.

The repository and `.github/workflows/c.cpp.yml` remain authoritative for implementation and CI behavior.
