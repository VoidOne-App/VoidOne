## 👁️ درباره VoidOne

پروژه‌ی **VoidOne** یک لانچر سریع، سبک و متن‌باز برای بازی‌های پی‌سی است که بر پایه‌ی **C++23** و **Qt 6 / QML** توسعه داده می‌شود. هدف این پروژه، جمع‌آوری یکپارچه‌ی بازی‌ها از استورهای مختلف (مثل Steam، Epic Games، GOG و Xbox) و اجرای مستقیم آن‌ها در یک محیط مدرن، با تم سایبرپانک و بدون برنامه‌های ردیابی و مصرف اضافه منابع است.

این برنامه در حالت آماده‌به‌کار (Idle) تقریباً هیچ قالبی از منابع سیستم را اشغال نمی‌کند و سرعت پاسخ‌دهی بالا و نرخ فریم روان را بر خدمات سنگین پس‌زمینه ترجیح می‌دهد. با جداسازی لایه رابط کاربری از منطق اجرایی، VoidOne کارایی بالا روی سخت‌افزارهای مختلف و حفظ کامل حریم خصوصی کاربر را تضمین می‌کند.

> ⚠️ **وضعیت پروژه:** VoidOne در مراحل اولیه توسعه قرار دارد و بخش‌های اصلی معماری آن به‌سرعت در حال بهبود و شکل‌گیری است.

## ✨ ویژگی‌های کلیدی

### 🎮 کتابخانه یکپارچه بازی‌ها
* **موتور اسکن خودکار:** اسکن دقیق حافظه، پوشه‌های سفارشی و فایل‌های پیکربندی استورها (Steam VDF، Epic AppData و GOG Galaxy SQLite) برای ساخت لیست مرجع بازی‌ها.
* **دریافت هوشمند متادیتا:** دریافت ناهمگام (Asynchronous) کاورهای باکیفیت، پس‌زمینه‌ها، امتیازات و اطلاعات سازندگان از طریق ارتباطات حافظه‌پنهان (Cache).
* **آمار بازی و حفظ حریم خصوصی:** ثبت محلی زمان بازی، تعداد اجرا و روند استفاده بدون ارسال حتی یک بایت داده به سرورهای خارجی.

### 🎨 رابط کاربری QML با تم سایبرپانک
* **رندر سخت‌افزاری:** اجرای روان با نرخ +۶۰ فریم و انیمیشن‌های باکیفیت به‌کمک رندر مستقیم GPU و QtQuick.
* **شخصی‌سازی گسترده:** معماری ماژولار UI با پشتیبانی از پوسته دارک، تغییر چیدمان و ساخت تم‌های سفارشی.

### 🧩 سیستم مدیریت ماد (Mod Engine)
* **پروفایل‌بندی مادها:** ساخت پروفایل‌های مجزا برای هر بازی با قابلیت فعال/غیرفعال‌سازی تک‌کلیکه.
* **ترتیب بارگذاری و اولویت:** بررسی وابستگی‌ها، مدیریت اولویت اجرا و لینک مجازی فایل‌های ماد بدون آسیب به فایل‌های اصلی بازی.

### 🤖 سیستم CI/CD با قابلیت ترمیم خودکار
* **ترمیم هوشمند کد:** تحلیل خطاهای بیلد در گیت‌هاب توسط سیستم هوش مصنوعی (Gemini 2.5 Pro + Qwen2.5-Coder) و ارسال خودکار Pull Request برای رفع خطاهای کامپایل C++ و CMake.

## 🔨 ساخت و کامپایل از سورس

### پیش‌نیازها
* **کامپایلر:** 
  * ویندوز: MSVC 2022 (نسخه v17.8 به بالا) با پشتیبانی کامل از C++23
  * لینوکس: GCC 13+ یا Clang 17+
* **فریم‌ورک:** Qt 6.8+ (به همراه ماژول‌های QtQuick و QML)
* **ابزارها:** CMake 3.25 یا بالاتر، Ninja Build System و Git 2.40+

### مراحل کامپایل

```bash
# ۱. دریافت کدها از گیت‌هاب
git clone [https://github.com/VoidOne-App/VoidOne.git](https://github.com/VoidOne-App/VoidOne.git)
cd VoidOne

# ۲. پیکربندی سیستم بیلد با استاندارد C++23
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_CXX_STANDARD=23

# ۳. کامپایل هم‌زمان پروژه
cmake --build build --config Release --parallel
