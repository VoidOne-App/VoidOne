## 👁️ درباره VoidOne

پروژه‌ی **VoidOne** یک هاب بازی‌های کامپیوتری فوق‌العاده بهینه، جامع، متن‌باز و مدیریت‌کننده کتابخانه است که از پایه با زبان **C++23** و **Qt 6 / QML** مهندسی شده است. این نرم‌افزار به عنوان یک اکوسیستم دسکتاپ یکپارچه طراحی شده است تا فاصله بین پلتفرم‌های توزیع بازی تجاری پراکنده (مانند استیم، اپیک گیمز، جی‌او‌جی و EA App) و اجرای خالص محلی را به طور کامل از بین ببرد.

بر خلاف لانچرهای سنتی مبتنی بر فناوری Electron که حجم زیادی از منابع سیستم را صرف رندر کردن رابط کاربری می‌کنند، VoidOne از رندرینگ شتاب‌یافته‌ی سخت‌افزاری جدا شده از منطق اجرای سطح پایین استفاده می‌کند. این امر مصرف رم در حالت آماده‌به‌کار (Idle) را نزدیک به صفر نگه می‌دارد و در عین حال یک رابط کاربری خیره‌کننده با الهام از سبک سایبرپانک ارائه می‌دهد که روی هر رزولوشن یا مقیاسی با سرعت ۶۰ فریم بر ثانیه اجرا می‌شود.

> ⚠️ **وضعیت توسعه:** VoidOne در حال حاضر در فاز توسعه‌ی فعال و فشرده قرار دارد. ای‌پی‌آی‌های هسته، شمای دیتابیس و تردهای پس‌زمینه با سرعت در حال تکامل هستند. لطفاً برای پیگیری پیشرفت‌ها به [نقشه راه استراتژیک](#-نقشه-راه-استراتژیک) مراجعه کنید.

## 🛡️ مانیفست — از گیمر برای گیمر

VoidOne در یک اتاق جلسات شرکتی متولد نشده است؛ بلکه توسط یک گیمر ساخته شده که ارزش ذاتی یکپارچگی نرم‌افزار و استقلال کاربر را عمیقاً درک می‌کند. ما معتقدیم نرم‌افزارهای گیمینگ باید به صورت شفاف عمل کنند و به حریم خصوصی، منابع سیستم و استقلال کاربر احترام بگذارند. دوران کلاینت‌های اجباری همیشه آنلاین DRM و پلتفرم‌های پر از تله‌متری دیگر به سر آمده است.

- ♾️ **همیشه آزاد و متن‌باز** — بدون پرداخت درون‌برنامه‌ای اجباری، بدون اشتراک‌های اجباری و بدون وابستگی‌های انحصاری شرکتی.
- 🔒 **حریم خصوصی مطلق و طراحی آفلاین‌محور** — بدون موتورهای تله‌متری، بدون ردیابی فعالیت‌ها و بدون پیکسل‌های تحلیلی پنهان. کل پایگاه داده و تاریخچه ساعت‌های بازی شما به صورت امن روی سیستم خودتان رمزنگاری می‌شود.
- ⚡ **معماری اجرایی فوق‌العاده سبک** — مهندسی‌شده برای زمان راه‌اندازی سرد کمتر از یک ثانیه و مصرف رم همیشه کمتر از ۵۰ مگابایت.
- 🎮 **حاکمیت کامل محلی** — مالکیت کامل و بی‌چون‌وچرا بر روی رجیستری بازی‌های محلی، فایل‌های تنظیمات و درخت‌های دایرکتوری مادها.
- 🧩 **بدون قفل اکوسیستم** — یک سیستم مدیریت کتابخانه مستقل و خودمختار که بدون نیاز به اینترنت با کارایی ۱۰۰ درصدی کار می‌کند.
- 🛠️ **توسعه‌ی متن‌باز شفاف** — ساختار کدی کاملاً قابل دسترس برای بازرسی عمومی، اعتبارسنجی امنیتی سخت‌گیرانه و مشارکت جامعه‌محور.

> **"من تا ابد کنار گیمرها می‌ایستم. سخت‌افزار شما، قوانین شما."**

## ✨ امکانات جامع سیستم

### 👻 موتور ارکستراسیون پردازش و اجرای گسسته (Ghost Launch)
- **اجرای مستقیم باینری:** دور زدن کامل سربار فروشگاه‌ها با اجرای مستقیم بازی‌ها از روی فایل‌های اجرایی اصلی (`.exe`, `.elf`) با استفاده از آرگومان‌های سفارشی خط فرمان (CLI).
- **بازیابی خودکار رم:** تشخیص خودکار کلاینت‌های اجباری DRM حین بازی، انتقال آن‌ها به حالت کم‌مصرف (Headless)، و پایان دادن به پردازش‌های پس‌زمینه فروشگاه پس از خروج از بازی برای بازگرداندن ۱۰۰٪ رم به سیستم‌عامل.
- **تزریق اولویت پردازنده:** امکان تزریق خودکار پرچم‌های اولویت بالای پردازنده (High یا Real-Time) به بازی‌های در حال اجرا مستقیماً از رابط کاربری.

### 🎮 تجمیع‌کننده چندفروشگاهی بازی‌ها
- **اسکن عمیق حافظه:** الگوریتم‌های چندنخی (Multi-threaded) برای بررسی دیسک‌ها، پارتیشن‌های سفارشی و مانیفست‌های پیچیده (فایل‌های Steam `appmanifest_*.acf`، اپیک گیمز `.item` و دیتابیس‌های SQLite پلتفرم GOG) جهت ساخت یک کتابخانه واحد.
- **دریافت غنی متادیتا:** دریافت خودکار پوسترهای باکیفیت، بنرهای پانوراما، توضیحات ترجمه‌شده، آمار زمان بازی و امتیازات متاکریتیک از طریق کارگرهای پس‌زمینه بهینه‌شده.
- **موتور تحلیل محلی:** ردیابی عادت‌های شخصی بازی کردن شامل طول جلسات، تعداد دفعات اجرا و گزارش‌های کرش، با ذخیره‌سازی امن در یک دیتابیس محلی سبک و ایمن SQLite.

### 🎨 رابط کاربری QML با الهام از سایبرپانک
- **شتاب‌دهی سخت‌افزاری بومی:** رابط کاربری مبتنی بر Qt/QML با استفاده از بک‌اند‌های OpenGL/Vulkan برای ارائه انیمیشن‌های نرم ۶۰+ فریم بر ثانیه، شیدرهای ذرات زنده و تأخیر پایین در ترد اصلی.
- **شخصی‌سازی ماژولار:** اکوسیستم پویای رابط کاربری با پشتیبانی از تغییر ساختار چیدمان، پالت‌های رنگی پویا، مقیاس‌گذاری فونت و سازگاری کامل با حالت تاریک (Dark Mode).

### 🧩 موتور پیشرفته مدیریت مادها
- **تنظیمات پروفایل اتمی:** ساخت پروفایل‌های مادینگ ایزوله برای هر بازی با قابلیت فعال‌سازی و غیرفعال‌سازی تک‌کلیکی آنی.
- **مپینگ فایل‌های مجازی (VFS):** استفاده از پیوندهای نمادین سیستم فایل مجازی برای تزریق مادها بدون رونویسی دائم یا آسیب به فایل‌های اصلی بازی.
- **ماتریس حل تداخل:** بررسی خودکار ترتیب بارگذاری فایل‌ها، شناسایی تداخل‌های عمیق مادها و اعتبارسنجی ساختار پیوندها پیش از اجرای موتور بازی.

### 🤖 سیستم عیب‌یابی و ترمیم خودکار هوش مصنوعی
- **پایپ‌لاین خودترمیمی CI/CD:** گردش‌های کاری ترکیبی هوش مصنوعی با استفاده از مدل Gemini برای عیب‌یابی به همراه ایجنت محلی Qwen برای پچ کردن کدها.
- **اصلاح خودکار:** تجزیه و تحلیل خطاهای کامپایلر CMake/C++ در گیت‌هاب اکشنز، شناسایی خط دقیق ایجادکننده خطا و پیشنهاد اصلاحات کاربردی از طریق Pull Request خودکار.

## ⚙️ پشته فناوری و زیرساخت موتور

- **هفت‌سین و منطق اصلی:** `C++23` — تضمین انتزاع بدون سربار، فراخوانی‌های سیستمی با تأخیر فوق‌العاده پایین و مدیریت دقیق پردازش‌ها.
- **فریم‌ورک رابط کاربری:** `Qt 6.8 / QML` — ارائه‌ی یک رابط دکوراتیو و شتاب‌یافته با معماری ماژولار مبتنی بر سیگنال و اسلات.
- **پایگاه داده رابطه‌ای:** `SQLite3` — یک راه حل ذخیره‌سازی سبک، ایمن و تعبیه‌شده برای مدیریت کتابخانه‌های حجیم محلی.
- **اتوماسیون ساخت:** `CMake 3.25+ / Ninja` — پایپ‌لاین تنظیمات ساخت مقیاس‌پذیر و چندپلتفرمی.
- **بسته‌بندی و استقرار:** `WiX Toolset v4 / MSI` — کامپایل یک نصب‌کننده‌ی ۶۴ بیتی بهینه برای ویندوز همراه با یکپارچه‌سازی منوی استارت و دسکتاپ.
- **یکپارچه‌سازی مداوم (CI/CD):** `GitHub Actions` — مدیریت کامپایل خودکار چندپلتفرمی، تحلیل ایستا با CodeQL و استقرار خودکار.

## 🔨 کامپایل و ساخت از سورس

مختص توسعه‌دهندگان، مشارکت‌کنندگان و بازرسان امنیتی که می‌خواهند VoidOne را به صورت محلی کامپایل کنند.

### پیش‌نیازهای جامع سیستمی
- **الزامات کامپایلر:**
  - **سیستم‌عامل ویندوز:** Microsoft Visual Studio 2022 (نسخه 17.8 به بالا) با پرچم‌های استاندارد C++23.
  - **سیستم‌عامل لینوکس:** GCC 13+ یا Clang 17+ با پشتیبانی کامل کتابخانه استاندارد.
- **نصب فریم‌ورک:** Qt 6.8+ (اطمینان حاصل کنید که ماژول‌های Desktop Development، QtQuick و QML انتخاب شده‌اند).
- **ابزار بسته‌بندی:** WiX Toolset v4 (فقط برای کامپایل فایل MSI ویندوز مورد نیاز است).
- **ابزارهای ساخت:** CMake 3.25+، موتور ساخت Ninja و Git 2.40+.

### مراحل گام‌به‌گام کامپایل

```bash
# ۱. کلون کردن مخزن اصلی و ورود به دایرکتوری پروژه
git clone [https://github.com/VoidOne-App/VoidOne.git](https://github.com/VoidOne-App/VoidOne.git)
cd VoidOne

# ۲. تنظیم محیط ساخت با استفاده از CMake و مولد Ninja
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_CXX_STANDARD=23

# ۳. کامپایل باینری‌های بهینه‌شده با استفاده از تمام هسته‌های پردازنده
cmake --build build --config Release --parallel

# ۴. تولید نصب‌کننده رسمی WiX v4 MSI (مخصوص ویندوز)
wix build -ext WixToolset.UI.wixext installer.wxs -o build/VoidOne-Setup-v0.0.1.msi
```

```
                      |
                      v
[ 💻 تولید پچ کد C++ توسط ایجنت Qwen Coder ]
                      |
                      v
[ 🔍 ارسال خودکار Pull Request جهت بررسی نهایی انسان ]
```

> *نکته امنیتی: هوش مصنوعی صرفاً در نقش مشاور و تولیدکننده عمل می‌کند. هیچ کد تولیدشده توسط هوش مصنوعی بدون بازرسی دقیق و تأیید نگه‌دارندگان اصلی وارد شاخه اصلی نمی‌شود.*

- [ ] **فاز ۶ — توسعه اکوسیستم:** انتشار کیت توسعه شخصی‌سازی تم، ایجاد هوک‌های همگام‌سازی سخت‌افزار RGB (از طریق OpenRGB) و فعال‌سازی پشتیبان‌گیری رمزنگاری‌شده از تنظیمات.

## 🤝 مشارکت مردمی

پروژه‌ی VoidOne بر پایه همکاری‌های متن‌باز رشد می‌کند. مشارکت در هر مقیاسی — از رفع باگ‌ها و بهبود مستندات گرفته تا پیاده‌سازی ویژگی‌های بزرگ و بازطراحی رابط کاربری — بسیار ارزشمند است.

1. **فورک (Fork)** کردن مخزن رسمی VoidOne به حساب کاربری گیت‌هاب خود.
2. **ساخت** یک شاخه (Branch) اختصاصی از `main`:
   ```bash
   git checkout -b feature/AdvancedGameScanner
   ```
3. **کامیت** تغییرات منطقی خود با پیام‌های واضح و توصیفی:
   ```bash
   git commit -m 'feat: implement multi-threaded directory scanning for Steam libraries'
   ```
4. **پوش (Push)** شاخه به مخزن فورک‌شده:
   ```bash
   git push origin feature/AdvancedGameScanner
   ```
5. **ارسال** یک Pull Request جامع با جزئیات تغییرات، توجیه منطقی و مراحل تست.
